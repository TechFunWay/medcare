# 用药管理（MedCare）

把每一次吃药、打针、输液都记清楚，家人可以一起管。

面向用药人与监护人的协作式用药本：药品库存、用药计划、到点提醒、打卡记录、处方识别与依从性统计。
当前版本 **v0.1.39**，已在飞牛 NAS 真机安装并完成通知渠道与处方识别的联调。

## 它解决什么问题

按医嘱长期吃药、打针、输液时，最容易出的问题不是"不知道要做什么"，而是：

- 到点忘了 —— 应用按计划提前、到点、逾期分三级提醒，直到完成或明确跳过；
- 做完没记 —— 一键打卡，误点可撤销，库存自动扣减；
- 剩多少不清楚 —— 批次库存 + 有效期 + 低库存预警；
- 复诊说不清 —— 完成率、漏服次数、按药品与时段分布，都能下钻到具体记录。

**它不做医疗建议**：不提供诊断、用药建议或剂量推荐，所有计划都由用户按医嘱录入。

## 功能一览

### 用药本与协作

- 一个账号可创建/加入多个用药本，顶部一键切换；
- 邀请链接、6 位邀请码、二维码三种加入方式；
- 管理员 / 监护人 / 成员三级权限：管理员由创建人担任并可转交；成员默认只能查看与「提醒用药」；
- **权限逐格勾选**：管理员决定谁是用药人，并对每位成员按「模块 × 动作」勾选——用药记录、药品与库存、用药计划、处方识别、图片资料、统计与日志、成员与邀请，
  每块都能单独决定能不能**看**、能不能**新增 / 修改 / 删除**（用药记录另有「点提醒」「点完成」两格）。勾了才有，不勾就没有：没勾查看，那一页连进都进不去。
  老人、孕妇、学生用药人各有搭手的人，把对应的格勾给实际动手的家人；另有「只读 / 帮忙照看 / 管药与计划 / 全部」四个预设可一键套用。

- 每位成员配置自己的通知渠道与订阅开关。

### 药品与库存

- 药品基础信息与库存分开：药品详情页分「基本信息 / 库存 / 出入库明细」三个标签；
- 药品、批次、入库（包装数 × 每包装含量）、盘点、调整、丢弃；
- 出入库明细记录**入库来源**（药店购买 / 医院开具 / 其他）与**录入来源**（手动 / 药盒 / 缴费单 / 处方 / 完成用药 / 盘点）；
- 完成用药时按「先到期先出」扣减批次并记出库，撤销按原明细恢复；识别导入、手动入库、处方确认都自动入库；
- 低库存阈值、临期预警天数可分别设置，首页与药品页都有提醒。

### 计划与执行

- 频率：每天、每 N 天、每周指定星期、每 N 小时；一条计划可设多个时间点；
- 长期计划与固定疗程都支持，保存前可预览未来 7 天；
- 今日按早上/中午/下午/晚上/夜间分组，逾期置顶；
- 结果：完成、撤销、漏服（手动 + 日终自动）、医生调整、自己调整、稍后提醒；
- 调整记录改前改后，历史记录不会被覆盖。

### 拍照识别与单据导入

- 药品页「拍照识别」支持三种单据：**药品包装盒**、**门诊收费凭据**、**处方笺**；
- 药盒读出名称、规格、厂家、有效期、包装内数量；缴费单按「逐条提取」把单子上的每种药都列出来，可勾选、全选、逐条修改后批量导入；
- **处方笺** → 生成每天几点的用药计划；**药盒 / 收费凭据** → 只建药品并按单据数量入库，不排计划；
- 逐项人工核对后才落库，低置信度字段会标「请核对」；批量导入走事务，建药品、写批次、记库存流水一次完成；
- 识别历史按单据类型区分标题，可点开重新核对，失败的记录一键重试；
- 原图默认不保存，可选加密留存。
- 识别服务配置支持不保存先测连接、先拉模型列表，模型可直接下拉选择。

### 提醒

| 渠道 | 说明 |
|---|---|
| 站内 | 通知中心 + 实时浮层，多端同步 |
| 邮件 | SMTP（465 SSL / 587 STARTTLS / 25），系统级配置 |
| 钉钉 | 群机器人 Webhook，支持加签与自定义关键词 |
| 飞书 | 群机器人 Webhook，支持签名与自定义关键词 |

- 提前提醒、到点提醒、逾期升级（默认 +15、+60 分钟）、每日总结；
- 按成员 fan-out，同一成员 90 秒内合并成一条；
- 失败按 1/2/4/8/16 分钟退避重试，投递日志可查可重试。

### 地点

- 居家、诊所、医院、药房、其他；计划可绑定地点；
- 某天临时换地方只改这一次，不影响后续；
- 事件卡片显示地址，支持复制与地图打开。

### 统计

- 完成率、当前漏服、曾漏服、连续无漏服天数、医生/自己调整次数；
- 趋势图、日历热力图、按药品与时段分布；
- 口径在页面上可解释，任一数字可下钻到具体记录。

### 主题与体验

- 亮色 / 暗色 / 跟随系统（白天亮色、晚上自动暗色）；
- 5 套配色：温润药本（默认）、清风医疗、深夜护航、柔光珊瑚、素简黑白；
- 手机端：底部标签栏、底部弹层、自定义日期/时间/选择器、PWA 可安装；
- 全应用禁止浏览器原生弹窗与原生日期/时间选择器。

## 技术架构

| 层 | 技术 |
|---|---|
| 后端 | Go + Gin + GORM + SQLite（WAL，单连接） |
| 调度 | 通知派发（每分钟）、每日总结、日终漏服结算（00:10）、库存对账（03:30） |
| 实时 | SSE 推送 + 修订号轮询兜底 |
| 前端 | Vue 3 + TypeScript + Vite + Pinia + Vue Router |
| 公共能力 | smallgo：认证、用户权限、系统配置、备份、审计、匿名统计 |

业务代码集中在 `server/medcare/`；数据边界是 `book_id`，非成员一律 404。

## 快速开始

> 忘记管理员密码？直接看 [重置管理员密码](#重置管理员密码忘记密码时)。

### 飞牛 NAS

应用中心 → 手动安装 → 从电脑上传，选择对应架构的 fpk（x86 / arm64）。安装向导确认端口（默认 8913），
完成后桌面出现「用药管理」图标，点击即用飞牛账号直接登录。

### Docker

```sh
docker run -d --name techfunway-medcare -p 8913:8913 \
  -v medcare-data:/app/data techfunways/medcare:latest
```

### 二进制

```sh
./medcare -port 8913 -data-dir ./data -web-dir ./static/dist
```

浏览器打开 `http://localhost:8913`，首个注册用户自动成为管理员。

### 用户管理与注册审核

管理员在「我的 → 用户管理」里可以新增用户、改用户名、改角色（管理员/普通用户）、
启用或禁用账号、重置密码、删除账号（不能删除或禁用自己，也不能取消自己的管理员身份）。

**超级管理员**：首次注册的那个账号就是超级管理员。它的设置任何账号都不能改——不能改名、
改角色、禁用、删除或重置密码，包括它自己；忘记密码只能用下面的命令行重置。普通用户可以被
提升为管理员，但普通管理员同样动不了超级管理员。

「偏好设置 → 管理员配置 → 注册审核」可打开「普通用户注册需审核」：打开后新注册的普通账号
处于「待审核」，登录会提示等待审核，管理员在用户管理里点「通过审核，允许登录」后才能使用；
首个注册的管理员不受影响。

## 重置管理员密码（忘记密码时）

不需要登录网页，在服务器上执行一次命令即可。**建议先停掉正在运行的服务**（避免和运行中的
进程同时写 SQLite），重置完再启动。

命令格式：

```sh
medcare -data-dir <该实例的数据目录> -reset-admin-password [-admin-password '新密码']
```

- 不加 `-admin-password`：随机生成一个强密码并**打印在终端**，照着复制即可；
- 加 `-admin-password '新密码'`：直接指定（至少 6 位）；
- 只重置**第一个管理员账号**的密码，并让该账号已签发的登录令牌全部失效；其它数据一律不动。

### 本机日常实例（`~/develop/apps/medcare`）

```sh
cd ~/develop/apps/medcare
./stop.sh
./bin/medcare -data-dir ./data -reset-admin-password
# 指定密码就加：-admin-password '你的新密码'
./start.sh
```

### 飞牛 NAS（fpk 安装）

先在应用中心把「用药管理」停掉，再在该应用安装目录执行（路径以应用中心显示为准，
一般在 `/vol1/@appstore/` 或 `/vol1/@appdata/` 下；`-data-dir` 指向这个应用自己的数据目录）：

```sh
cd /vol1/@appstore/techfunway-medcare          # 换成实际安装目录
./medcare -data-dir /vol1/@appdata/techfunway-medcare -reset-admin-password
```

执行完回应用中心启动应用，用新密码登录。路径不确定时看应用详情里的「安装位置 / 数据目录」。

### Docker

```sh
docker exec -it <容器名> /app/medcare -data-dir /data -reset-admin-password
# 或停容器后一次性执行：
# docker run --rm -v <数据卷>:/data <镜像> -data-dir /data -reset-admin-password
```

### 裸二进制

```sh
./medcare -data-dir ./data -reset-admin-password
```

## 关键约定

- **端口** 8913；`config.go`、`app.json`、`fnpack/manifest`、向导、Docker 必须一致。
- **包名** techfunway-medcare；网关前缀 `/app/techfunway-medcare`；数据目录同名。
- **飞牛入口** `type: url` 新页面打开，`protocol: ""` + 网关字段。
- **时区** 固定北京时间，前端格式化不受设备时区影响；存储与比较统一 UTC。
- **数据边界** 所有业务数据带 `book_id`，先校验成员身份。
- **禁止原生弹窗** `alert/confirm/prompt` 一律不用，日期/时间/下拉也自定义。
- **手机端** 375×667 无横向滚动；输入 16px；触控 44px；无重模糊动画。
- **安全** 通知/AI/SMTP 密钥 AES-GCM 加密；邀请 token 只存哈希；处方图私有。
